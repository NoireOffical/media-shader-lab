# v0.3.0 — Complete GPU video pipeline showcase

This Pre-release freezes the current portfolio milestone: a visible FFmpeg-to-OpenGL-to-H.265 data path with interactive controls, reproducible performance telemetry, and encode-quality validation.

## Demonstrated workflows

- Decode the bundled 720p/30 FPS H.264 sample through the FFmpeg software path.
- Render a moving frame through the real Dear ImGui dashboard and GLSL `original`, `grayscale`, `edge`, and `vignette` filters.
- Export each processed stream through the application's H.265/libx265 path.
- Present the four outputs side by side in a README GIF and the full-resolution `media-shader-lab-demo.mp4` Release asset.
- Preserve source attribution to Blender Foundation's Big Buck Bunny sample under CC BY 3.0.

## Verification

- `make build`
- `make test`
- Hidden-context snapshot and UI-snapshot smoke tests against frame 90 of the bundled sample
- Four 180-frame application exports using `original`, `grayscale`, `edge`, and `vignette`
- H.265 decode check followed by browser-compatible H.264/yuv420p packaging
- Visual review of the dashboard frame, dynamic four-panel comparison, README GIF, and Release MP4

## Known limitations

- The interactive renderer targets macOS OpenGL/GLFW. Linux CI validates the supported non-UI modules and project configuration, while VideoToolbox and IOSurface zero-copy paths require macOS hardware.
- VMAF is optional and was not enabled in the isolated recording environment; PSNR/SSIM and VMAF-capable build instructions remain documented separately.
- The GitHub demo shows representative filters and software encoding. It is not a cross-device performance benchmark and does not claim the displayed measurements are portable.

## Upgrade and compatibility

- This release adds documentation and generated showcase media only; application options, shader behavior, test assets, and encoded-file contracts are unchanged.
- The lightweight GIF remains in Git history. The larger H.264 MP4 is attached to the GitHub Pre-release rather than committed to the repository.
